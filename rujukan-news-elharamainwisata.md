| Situs | Isi |

| moh.gov.sa | Kementerian Kesehatan Saudi: syarat vaksin dan kesehatan jemaah |
| visa.mofa.gov.sa | Kementerian Luar Negeri Saudi: visa umrah dan haji |
| [arabnews.com](https://www.arabnews.com/) | Media Saudi berbahasa Inggris |
| saudigazette.com.sa | Media Saudi berbahasa Inggris |
| okaz.com.sa | Media Saudi berbahasa Arab |

Catatan: haj.gov.sa, spa.gov.sa, dan arabnews.com bisa diakses dari lingkungan riset ini. nusuk.sa
merespons tetapi menolak klien non-browser (406). Situs lain diblokir oleh proxy di sini, jadi belum diverifikasi
langsung, tetapi domainnya dikenal sebagai domain resmi.
